# Estudos de Java

Exercícios e anotações usados para consolidar fundamentos da linguagem e
conceitos de design. Os exemplos desta pasta são estudos isolados; projetos
com build e testes automatizados ficam em [`../projetos`](../projetos).

## Mapa

| Tópico | Diretório | Conteúdo |
| --- | --- | --- |
| Orientação a objetos | [`objetos`](objetos) | Classes, composição e modelagem |
| Design de software | [`padroes-de-projeto`](padroes-de-projeto) | Factory, construtores e encapsulamento |
| Concorrência | [`concorrencia`](concorrencia) | Threads e exercícios iniciais |
| Collections | [`arraylist`](arraylist) | Manipulação e refatoração de listas |
| Entrada e saída | [`entrada-saida`](entrada-saida) | Leitura e parsing de CSV |
| Memória | [`gerenciamento-de-memoria`](gerenciamento-de-memoria) | JVM, referências e coleta de lixo |
| Exercícios de domínio | [`exercicios`](exercicios) | Simuladores e modelagem em evolução |

Alguns diretórios representam etapas intermediárias do aprendizado e podem
conter implementações incompletas. Eles não são apresentados como projetos
finalizados.
