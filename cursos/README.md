# Exercícios de cursos

Exercícios produzidos durante cursos e trilhas guiadas. Os nomes foram
normalizados para facilitar a navegação; cada implementação representa a etapa
do curso em que foi criada.

- [`java-completo`](java-completo): fundamentos e orientação a objetos em Java.
- [`javascript-meta`](javascript-meta): introdução à programação com JavaScript.
- [`web-completo`](web-completo): fundamentos de JavaScript e desenvolvimento web.

Projetos autorais e executáveis ficam separados em [`../projetos`](../projetos).
